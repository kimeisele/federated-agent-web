# Golden test vectors

Static fixtures for a **second, independent implementation** to reproduce
without importing the Python package. Every file is plain JSON, hex, or raw
bytes; reproducibility requires only RFC 8785 (JCS), SHA-256, and Ed25519.

## Layout

```text
canonicalization/   input JSON + expected canonical bytes (hex) per case
signatures/         message + canonical bytes + content digest + keypair
delegations/        fully signed delegation + digest + issuer manifest
receipts/           artifact bytes + digest + signed receipt + digest
```

## How to reproduce

1. **Canonical bytes** — parse `<case>.json` with a strict JCS serializer that
   rejects duplicate members, NaN/Infinity, negative zero, and out-of-domain
   numbers, then sort object keys and serialize numbers exactly per RFC 8785.
   Compare to `<case>.canonical.hex` (lowercase hex of the UTF-8 bytes).
2. **Content digest** — `sha256:<hex>` of `SHA-256(JCS(document minus the
   top-level "signature" member))`.
3. **Key ID** — `sha256:<hex>` of `SHA-256(raw 32-byte Ed25519 public key)`.
4. **Signature** — Ed25519 over the canonical bytes; `base64url` without
   padding. Verify against the public key from `keypair.json` /
   `issuer-manifest.json` / `executor-manifest.json` key entries.
5. **Delegation digest** — content digest of `delegation.json` (compare
   `delegation-digest`).
6. **Receipt digest** — content digest of `receipt.json` (compare
   `receipt-digest`).
7. **Artifact digest** — `sha256:<hex>` of `SHA-256(artifact.bin)` over the
   exact raw bytes (compare `artifact-digest`).

## Key hygiene

The keys in `signatures/keypair.json` and the manifests under
`delegations/` and `receipts/` are **ephemeral TEST-ONLY keys** generated by
`tools/gen_vectors.py`. They must never be used outside tests. Regenerate
everything with:

```bash
python tools/gen_vectors.py
```
